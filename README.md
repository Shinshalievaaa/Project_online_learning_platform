# Atomic Habits Tracker API

Backend-сервис REST API для трекинга привычек, разработанный по книги «Атомные привычки» Джеймса Клира.

---

## Основной функционал

1. **Управление привычками:**
   * Разделение привычек на полезные и приятные.
   * Привязка вознаграждений или связанных приятных привычек.
   * Установка периодичности (не реже 1 раза в 7 дней) и времени на выполнение (не более 120 секунд).
   * Возможность сделать привычку публичной.

2. **Права доступа:**
   * Каждый пользователь имеет доступ только к своим личным привычкам.
   * Просмотр списка публичных привычек доступен всем авторизованным пользователям без права их редактирования или удаления.

3. **Фоновые уведомления:**
   * Ежеминутный мониторинг запланированных привычек через Celery Beat.
   * Автоматическая отправка сообщений-напоминаний в Telegram-бот при совпадении времени.
